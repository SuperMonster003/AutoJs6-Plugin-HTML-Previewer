파일 관리자에서 HTML Previewer를 사용합니다:

1. `HTML Previewer` 플러그인을 설치하고 활성화합니다.
2. 지원되는 HTML 또는 MHTML 파일의 더보기 메뉴를 엽니다.
3. `HTML 미리보기`를 선택합니다.

플러그인은 content URI를 통해 선택한 파일과 상위 디렉터리에 대한 임시 읽기 권한을 받습니다. 원시 파일 시스템 경로는 받지 않습니다.

지원 확장자: `html`, `htm`, `shtm`, `shtml`, `xht`, `xhtml`, `mht`, `mhtml`.

MHTML은 아카이브의 HTML 루트를 선택하고 허용된 내장 스타일, 이미지, 글꼴, 오디오, 동영상을 격리된 가상 출처에 연결합니다. 위치와 콘텐츠 ID는 내부 레이블일 뿐이며 모호한 레이블은 무시하고 저장소에는 아무것도 추출하지 않습니다.

스크립트는 기본적으로 비활성화됩니다. 신뢰할 수 있는 완전한 일반 HTML 파일에서는 설정의 상호작용 모드를 켜면 JavaScript, 버튼 이벤트, WebGL, 로컬 저장소를 사용할 수 있습니다. MHTML, 잘린 HTML, 소스 보기, PDF 내보내기는 항상 스크립트를 비활성화합니다. 쿠키, 직접 파일/content 접근, 네이티브 JavaScript 브리지, 새 창은 계속 비활성화됩니다. 상호작용 모드만 설정과 점수를 위한 로컬 저장소를 허용합니다. 소스 보기와 PDF는 다시 정제한 내용을 사용합니다.

뷰어는 페이지 내 검색, 글자 크기 조절, 테마 선택도 지원합니다. BOM, MIME 문자 집합, 파일 앞부분의 HTML 인코딩 선언을 인식합니다. 8 MB를 넘는 일반 HTML은 확인 후 처음 8 MB만 잘린 위치와 함께 표시할 수 있지만 MHTML은 완전해야 하므로 8 MB 초과 시 거부합니다.

뷰어 메뉴에서 `소스 보기`를 선택하면 원문을 읽기 전용 고정폭 형식으로 확인할 수 있고 `미리보기 보기`로 돌아갑니다. 소스 모드에서는 태그를 항상 문자 그대로 표시하며 모든 외부 요청을 차단합니다.

로컬 리소스는 허용된 폴더 또는 선택한 MHTML에서 읽습니다. 안전 모드는 공개 HTTPS 이미지를 허용하고, 상호작용 모드는 네트워크 리소스를 켜면 공개 HTTPS 스크립트, 스타일, 요청도 허용합니다. 네트워크를 끄면 WebView 외부 요청을 차단합니다. 상호작용 스크립트는 원격 서비스에 페이지 데이터를 보낼 수 있으므로 신뢰할 수 있는 페이지에서만 사용하세요.

`PDF 내보내기`를 선택하면 다시 읽고 정리한 밝은 테마 사본으로 Android 시스템 인쇄 화면을 엽니다. 소스 보기에서 내보내도 동일하며 현재 뷰어 상태는 바뀌지 않습니다. 시스템 화면에서 `PDF로 저장`과 대상 위치를 선택하세요. 플러그인은 저장소 권한을 요청하지 않습니다.

Explorer Action v2는 단일 파일의 기본 미리보기 버튼과 메뉴를 지원하며 문서와 상위 폴더의 임시 읽기 권한을 사용합니다. AutoJs6 빌드 5269 이상이 필요합니다.

메뉴와 대화상자는 AutoJs6 언어와 다크 모드를 따릅니다. GitHub (Auto)와 HTML 자동 테마도 동일합니다. 도구 모음과 시스템 표시줄은 렌더링 영역 가장자리의 대표색과 대비되는 검정 또는 흰색 글자 및 아이콘을 사용합니다. 그라데이션, 이미지, 애니메이션에서는 다시 로드할 때까지 색을 고정하여 깜박임을 방지합니다.
