HTML Previewer는 브라우저를 열지 않고 AutoJs6 안에서 HTML과 MHTML 파일을 미리 봅니다. 페이지는 기본적으로 스크립트를 실행하지 않는 안전 모드로 표시되며, 소스 보기, 페이지에서 찾기, PDF 내보내기도 할 수 있습니다. 미리보기는 파일을 읽기만 하며 원본 파일을 수정하지 않습니다.

### 시작하기

1. AutoJs6의 "플러그인 센터"에서 이 플러그인이 활성화되어 있는지 확인합니다.
2. AutoJs6 파일 관리자를 열고 HTML 또는 MHTML 파일을 찾습니다.
3. 파일 메뉴에서 "HTML 미리보기"를 선택합니다 (AutoJs6 6.8.1 이상에서는 최상위 메뉴 "HTML Previewer" 아래에 있습니다).
4. 미리보기 화면 오른쪽 위의 메뉴에서 찾기, 소스 보기, PDF 내보내기, "설정" 등을 사용합니다.

### 주요 기능

- **페이지에서 찾기**: 입력한 텍스트와 일치하는 부분을 강조 표시하고, 일치 항목 사이를 이동할 수 있습니다.
- **소스 보기**: 원본 텍스트를 읽기 전용 고정폭 레이아웃으로 표시합니다. "미리보기 보기"를 선택하면 페이지로 돌아갑니다.
- **PDF 내보내기**: 시스템 인쇄 화면을 열어 PDF로 저장과 저장 위치를 선택합니다. 플러그인에는 저장소 권한이 필요하지 않습니다.
- **상호작용 모드**: "설정"에서 켜면 스크립트가 실행되어 버튼, 애니메이션, 로컬 저장소가 작동합니다. 새 미리보기마다 다시 꺼지므로 신뢰할 수 있는 페이지에서만 켜세요.
- **네트워크 리소스**: "네트워크 이미지 불러오기"를 켜면 HTTPS 이미지를 표시합니다. 상호작용 모드가 켜져 있으면 이 항목이 "네트워크 리소스 불러오기"로 바뀌고 HTTPS 스크립트와 스타일도 허용합니다.
- **글자 크기와 테마**: "설정"에서 "글자 크기"를 조절하고 테마를 "AutoJs6 따르기", "라이트", "다크" 중에서 고릅니다.
- **전체 화면 모드**: 도구 모음을 숨겨 읽기에 집중할 수 있습니다. "전체 화면 모드로 시작"을 켜면 매번 전체 화면으로 미리 봅니다.
- **MHTML 아카이브**: 웹 아카이브 안의 페이지를 포함된 스타일, 이미지, 글꼴과 함께 표시하며, 저장소에 아무것도 풀어 놓지 않습니다.

### 요구 사항

- Android 7.0 이상.
- AutoJs6 6.8.0 이상.
- 저장소 권한이 필요하지 않습니다. 플러그인은 선택한 파일과 그 폴더만 읽으며, 네트워크는 HTTPS 리소스를 불러올 때만 사용합니다.

### 자주 묻는 질문

**버튼과 애니메이션이 반응하지 않는 이유**

페이지는 기본적으로 스크립트를 실행하지 않습니다. 신뢰할 수 있는 완전한 HTML 파일이라면 "설정"에서 "상호작용 모드"를 켜세요. MHTML 파일, 앞부분만 표시한 큰 파일, 소스 보기에서는 항상 스크립트를 실행하지 않습니다.

**일부 이미지나 스타일이 표시되지 않는 이유**

로컬 이미지와 스타일은 HTML 파일이 있는 폴더나 그 하위 폴더에 있어야 합니다. 네트워크 이미지는 "네트워크 이미지 불러오기"를 켜야 하며 HTTPS 주소만 지원합니다.

**큰 파일의 앞부분만 표시되는 이유**

8 MB를 넘는 HTML 파일은 먼저 확인을 거친 뒤 앞부분 8 MB만 표시하고 잘린 위치를 표시합니다. MHTML 아카이브는 전체를 표시해야 하므로 8 MB를 넘으면 미리 볼 수 없습니다.

**파일 메뉴에 "HTML 미리보기"가 없는 이유**

이 플러그인은 확장자가 html, htm, shtm, shtml, xht, xhtml, mht, mhtml인 파일만 처리합니다. 파일 확장자를 확인하고, "플러그인 센터"에서 이 플러그인이 활성화되어 있는지 확인하세요.

자세한 내용은 [프로젝트 페이지](https://github.com/SuperMonster003/AutoJs6-Plugin-HTML-Previewer)를 참고하세요.
