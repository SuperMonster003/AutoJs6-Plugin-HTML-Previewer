파일 관리자에서 HTML Preview를 사용합니다:

1. `HTML Preview` 플러그인을 설치하고 활성화합니다.
2. 지원되는 HTML 파일의 더보기 메뉴를 엽니다.
3. `HTML 미리보기`를 선택합니다.

플러그인은 content URI를 통해 선택한 파일과 상위 디렉터리에 대한 임시 읽기 권한을 받습니다. 원시 파일 시스템 경로는 받지 않습니다.

지원 확장자: `html`, `htm`, `shtm`, `shtml`, `xht`, `xhtml`.

뷰어는 표시 전에 콘텐츠를 정리합니다. 스크립트, 이벤트 처리기 속성, 프레임, 포함된 개체, 안전하지 않은 리소스 주소를 제거합니다. JavaScript, WebView 저장소, 쿠키, 직접 파일 접근은 비활성화 상태로 유지됩니다.

버전 1은 파일 관리자의 단일 파일 읽기 전용 작업만 지원합니다.
