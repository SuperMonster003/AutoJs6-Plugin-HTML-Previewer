استخدم HTML Previewer من مدير الملفات:

1. ثبت المكون `HTML Previewer` وقم بتمكينه.
2. افتح القائمة الإضافية لملف HTML أو MHTML مدعوم.
3. اختر `معاينة HTML`.

يتلقى المكون إذن قراءة مؤقتا للملف المحدد والمجلد الأصل عبر content URI. لا يتلقى مسارا خاما لنظام الملفات.

الامتدادات المدعومة: `html`, `htm`, `shtm`, `shtml`, `xht`, `xhtml`, `mht`, `mhtml`.

في MHTML يختار العارض جذر HTML من الأرشيف ويربط الأنماط والصور والخطوط والصوت والفيديو المضمنة المسموح بها بأصل افتراضي معزول. المواقع ومعرفات المحتوى تسميات داخلية فقط; وتتجاهل التسميات الملتبسة ولا يستخرج شيء إلى التخزين.

تكون البرامج النصية معطلة افتراضيا. لملف HTML عادي كامل وموثوق, فعّل الوضع التفاعلي في الإعدادات لتشغيل JavaScript وأحداث الأزرار وWebGL والتخزين المحلي. تبقى النصوص معطلة دائما في MHTML وHTML المقتطع وعرض المصدر وتصدير PDF. تبقى ملفات الارتباط والوصول المباشر إلى الملفات/content وجسور JavaScript الأصلية والنوافذ الجديدة معطلة. يسمح الوضع التفاعلي فقط بالتخزين المحلي للتفضيلات ونتائج الألعاب. يستخدم المصدر وPDF محتوى منقحا من جديد.

يدعم العارض أيضا البحث داخل الصفحة وضبط حجم النص واختيار السمة. يتعرف على BOM ومجموعة محارف MIME وإعلانات ترميز HTML المبكرة. يتطلب HTML العادي الأكبر من 8 MB تأكيدا قبل عرض أول 8 MB مع تحديد الاقتطاع; أما MHTML فيجب أن يبقى كاملا ويرفض عند تجاوز 8 MB.

اختر `عرض المصدر` من قائمة العارض لفحص النص الأصلي بتخطيط ثابت العرض وللقراءة فقط, ثم اختر `عرض المعاينة` للعودة. تبقى الوسوم نصا حرفيا في وضع المصدر وتحجب جميع الطلبات الصادرة.

تُقرأ الموارد المحلية من المجلد المصرح به أو أرشيف MHTML المحدد. يسمح الوضع الآمن بصور HTTPS العامة, ويسمح الوضع التفاعلي أيضا بالنصوص والأنماط والطلبات العامة عبر HTTPS عند تفعيل موارد الشبكة. يؤدي تعطيل الشبكة إلى حظر طلبات WebView الصادرة. تستطيع النصوص التفاعلية إرسال بيانات الصفحة إلى خدمات بعيدة, لذا فعّلها للصفحات الموثوقة فقط.

اختر `تصدير PDF` لفتح لوحة الطباعة في Android بنسخة أعيدت قراءتها وتنقيتها وبسمة فاتحة. ينطبق ذلك أيضا عند التصدير من عرض المصدر ولا تتغير حالة العارض الحالية. اختر `حفظ كملف PDF` والوجهة في واجهة النظام; لا يطلب الملحق إذن التخزين.

يدعم Explorer Action v2 زر العرض الرئيسي وقائمة الملف الواحد مع إذن قراءة مؤقت للمستند والمجلد الأب. يلزم AutoJs6 بالإصدار الداخلي 5269 أو أحدث.

تتبع القوائم والحوارات لغة AutoJs6 والوضع الداكن, وكذلك GitHub (Auto) وسمة HTML التلقائية. تستخدم الأشرطة لونا ممثلا لحواف الصفحة مع نصوص وأيقونات سوداء أو بيضاء متباينة. يبقى اللون ثابتا حتى إعادة التحميل مع التدرجات والصور والرسوم المتحركة لتجنب الوميض.
