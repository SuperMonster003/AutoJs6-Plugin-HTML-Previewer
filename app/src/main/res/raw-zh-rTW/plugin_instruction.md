在檔案管理器中使用 HTML Previewer:

1. 安裝並啟用 `HTML Previewer` 外掛.
2. 開啟一個受支援 HTML 或 MHTML 檔案的更多選單.
3. 選擇 `預覽 HTML`.

外掛透過 content URI 暫時取得所選檔案及其上層目錄的讀取權限. 外掛不會接收原始檔案系統路徑.

支援的副檔名: `html`, `htm`, `shtm`, `shtml`, `xht`, `xhtml`, `mht`, `mhtml`.

對於 MHTML, 檢視器會選擇封存檔的 HTML 根部件, 並將類型允許的嵌入樣式, 圖片, 字型, 音訊和影片映射至隔離虛擬來源. 封存檔位置與內容 ID 只作為內部標籤; 歧義標籤會被忽略, 任何內容都不會解壓至儲存空間.

預設停用指令碼. 對於可信的完整一般 HTML 檔案, 可在 `設定` 中開啟 `互動模式`, 支援 JavaScript, 按鈕事件, WebGL 和本機儲存. MHTML, 截斷 HTML, 原始碼檢視和 PDF 匯出始終停用指令碼. Cookie, 直接檔案/content 存取, 原生 JavaScript 橋和新視窗保持停用. 安全模式停用頁面儲存; 互動模式允許本機儲存, 用於頁面偏好或遊戲分數. 原始碼檢視與 PDF 使用重新淨化的內容.

檢視器也支援頁內搜尋, 字號調整和主題選擇. 它能識別 BOM, MIME 字元集與檔案前部的 HTML 編碼宣告. 超過 8 MB 的普通 HTML 需確認後才會僅顯示前 8 MB 並標出截斷位置; MHTML 必須保持完整, 超過 8 MB 時會被拒絕.

可在檢視器選單中選擇 `檢視原始碼`, 以唯讀等寬排版檢查原始文字, 再選擇 `檢視預覽` 返回. 原始碼模式下標籤始終按原文顯示, 並會封鎖所有對外請求.

本機資源來自已授權目錄或選取的 MHTML 封存檔. 安全模式允許公共 HTTPS 圖片; 互動模式開啟 `載入網路資源` 後亦允許公共 HTTPS 指令碼, 樣式及請求. 關閉網路開關會攔截 WebView 對外請求. 互動指令碼能夠向遠端服務傳送頁面資料, 因此僅應對可信頁面啟用.

選擇 `匯出 PDF` 會使用重新讀取, 淨化並強制淺色的副本開啟 Android 系統列印介面. 從原始碼檢視發起時也遵循相同流程, 且不會改變目前檢視器狀態. 請在系統介面中選擇 `另存為 PDF` 及目標位置; 外掛程式不申請儲存空間權限.

Explorer Action v2 同時支援單一檔案的主預覽按鈕和溢位選單, 透過暫時唯讀授權存取文件及其父目錄. 需要 AutoJs6 組建 5269 或更新版本.

選單和對話方塊跟隨 AutoJs6 的語言與深色模式. GitHub (Auto) 和 HTML 自動佈景主題也跟隨 AutoJs6. 工具列及系統列使用算繪頁面邊緣的代表色, 配合有對比度的黑色或白色文字與圖示. 漸層, 圖片和動畫背景取色後保持穩定, 重新載入時更新, 避免閃爍.
