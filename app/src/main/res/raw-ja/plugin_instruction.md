HTML Previewer は, ブラウザーを開かずに AutoJs6 の中で HTML と MHTML ファイルをプレビューします. ページは既定でスクリプトを実行しない安全モードで表示され, ソースの表示, ページ内検索, PDF へのエクスポートもできます. プレビューは読み取りのみで, 元のファイルは変更しません.

### はじめに

1. AutoJs6 の "プラグインセンター" で本プラグインが有効になっていることを確認します.
2. AutoJs6 のファイルマネージャーを開き, HTML または MHTML ファイルを探します.
3. ファイルメニューから "HTML をプレビュー" を選びます (AutoJs6 6.8.1 以降では最上位メニュー "HTML Previewer" の中にあります).
4. プレビュー画面右上のメニューから, 検索, ソースの表示, PDF のエクスポート, "設定" などを使います.

### 主な機能

- **ページ内を検索**: 入力した語句に一致する箇所を強調表示し, 一致箇所の間を移動できます.
- **ソースを表示**: 元のテキストを読み取り専用の等幅レイアウトで表示します. "プレビューを表示" を選ぶとページに戻ります.
- **PDF をエクスポート**: システムの印刷画面を開き, PDF として保存と保存先を選びます. プラグインにストレージの権限は不要です.
- **インタラクティブモード**: "設定" でオンにするとスクリプトが実行され, ボタン, アニメーション, ローカルストレージが動作します. 新しいプレビューのたびにオフに戻るので, 信頼できるページでのみオンにしてください.
- **ネットワークリソース**: "ネットワーク画像を読み込む" をオンにすると HTTPS の画像を表示します. インタラクティブモードがオンのときはこの項目が "ネットワークリソースを読み込む" になり, HTTPS のスクリプトとスタイルも許可します.
- **文字サイズとテーマ**: "設定" で "文字サイズ" を調整し, テーマを "AutoJs6 に従う", "ライト", "ダーク" から選びます.
- **全画面モード**: ツールバーを隠して読むことに集中できます. "全画面モードで開始" をオンにすると, 毎回全画面でプレビューします.
- **MHTML アーカイブ**: Web アーカイブ内のページを, 埋め込まれたスタイル, 画像, フォントとともに表示します. ストレージには何も展開しません.

### 動作要件

- Android 7.0 以降.
- AutoJs6 6.8.0 以降.
- ストレージの権限は不要です. プラグインは選んだファイルとそのフォルダーだけを読み取り, ネットワークは HTTPS のリソースを読み込むときだけ使います.

### よくある質問

**ボタンやアニメーションが反応しない理由**

ページは既定ではスクリプトを実行しません. 信頼できる完全な HTML ファイルであれば, "設定" で "インタラクティブモード" をオンにします. MHTML ファイル, 先頭部分だけを表示している大きなファイル, ソース表示では常にスクリプトを実行しません.

**一部の画像やスタイルが表示されない理由**

ローカルの画像とスタイルは, HTML ファイルと同じフォルダーかそのサブフォルダーに置く必要があります. ネットワーク画像は "ネットワーク画像を読み込む" をオンにする必要があり, HTTPS のアドレスだけに対応します.

**大きなファイルの先頭部分だけが表示される理由**

8 MB を超える HTML ファイルは, 確認のうえ先頭の 8 MB だけを表示し, 途切れた位置を示します. MHTML アーカイブは全体を表示する必要があるため, 8 MB を超えるとプレビューできません.

**ファイルメニューに "HTML をプレビュー" がない理由**

本プラグインが扱うのは拡張子が html, htm, shtm, shtml, xht, xhtml, mht, mhtml のファイルだけです. ファイルの拡張子を確認し, "プラグインセンター" で本プラグインが有効になっていることを確認してください.

詳しくは [プロジェクトページ](https://github.com/SuperMonster003/AutoJs6-Plugin-HTML-Previewer) をご覧ください.
