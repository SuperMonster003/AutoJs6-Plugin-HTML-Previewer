ファイルマネージャーで HTML Previewer を使用します:

1. `HTML Previewer` プラグインをインストールして有効にします.
2. 対応する HTML または MHTML ファイルのオーバーフローメニューを開きます.
3. `HTML をプレビュー` を選択します.

プラグインは content URI を通じて選択したファイルと親ディレクトリの一時読み取り権限を受け取ります. 生のファイルシステムパスは受け取りません.

対応拡張子: `html`, `htm`, `shtm`, `shtml`, `xht`, `xhtml`, `mht`, `mhtml`.

MHTML ではアーカイブの HTML ルートを選択し, 許可された埋め込みスタイル, 画像, フォント, 音声, 動画を隔離仮想オリジンへ対応付けます. 場所とコンテンツ ID は内部ラベルにすぎず, 曖昧なラベルは無視され, ストレージへは何も展開しません.

スクリプトは既定で無効です. 信頼できる完全な通常 HTML ファイルでは設定のインタラクティブモードを有効にすると JavaScript, ボタンイベント, WebGL, ローカルストレージが使えます. MHTML, 切り詰めた HTML, ソース表示, PDF 出力では常にスクリプトを無効にします. Cookie, ファイル/content への直接アクセス, ネイティブ JavaScript ブリッジ, 新規ウィンドウは無効のままです. インタラクティブモードのみ設定やスコア用のローカルストレージを許可します. ソース表示と PDF には再度無害化した内容を使用します.

ビューアーはページ内検索, 文字サイズ調整, テーマ選択にも対応します. BOM, MIME 文字セット, ファイル先頭付近の HTML エンコーディング宣言を認識します. 8 MB を超える通常 HTML は確認後に先頭 8 MB のみを切り詰め位置付きで表示できますが, MHTML は完全な状態が必要なため 8 MB 超過時は拒否します.

ビューアーメニューの `ソースを表示` を選ぶと, 元のテキストを読み取り専用の等幅表示で確認でき, `プレビューを表示` で戻れます. ソースモードではタグを常に文字として表示し, 外向きリクエストをすべて遮断します.

ローカル資源は許可されたディレクトリまたは選択した MHTML 内から読み込みます. 安全モードでは公開 HTTPS 画像を許可し, インタラクティブモードではネットワーク資源を有効にすると公開 HTTPS のスクリプト, スタイル, 通信も許可します. ネットワークを無効にすると WebView の外部通信を遮断します. スクリプトはページのデータを外部へ送信できるため, 信頼できるページでのみ有効にしてください.

`PDF をエクスポート` を選ぶと, 再読み込みしてサニタイズし, ライトテーマに固定したコピーで Android のシステム印刷画面を開きます. ソース表示から書き出す場合も同じで, 現在のビューアー状態は変わりません. システム画面で `PDF として保存` と保存先を選んでください. プラグインはストレージ権限を要求しません.

Explorer Action v2 は単一ファイルのメインプレビューボタンとメニューに対応し, 文書と親ディレクトリへの一時的な読み取り権限を使用します. AutoJs6 ビルド 5269 以降が必要です.

メニューとダイアログは AutoJs6 の言語とダークモードに従います. GitHub (Auto) と HTML 自動テーマも同様です. ツールバーとシステムバーには描画領域の端から取得した代表色を使い, 文字とアイコンは対比のある黒または白にします. グラデーション, 画像, アニメーションでは再読み込みまで色を固定してちらつきを防ぎます.
