Используйте HTML Previewer в файловом менеджере:

1. Установите и включите плагин `HTML Previewer`.
2. Откройте дополнительное меню поддерживаемого файла HTML.
3. Выберите `Предпросмотр HTML`.

Плагин получает временный доступ на чтение выбранного файла и его родительского каталога через URI содержимого. Он не получает исходный путь файловой системы.

Поддерживаемые расширения: `html`, `htm`, `shtm`, `shtml`, `xht`, `xhtml`.

Средство просмотра очищает содержимое перед отображением. Оно удаляет скрипты, атрибуты обработчиков событий, фреймы, встроенные объекты и небезопасные адреса ресурсов. JavaScript, хранилище WebView, файлы cookie и прямой доступ к файлам остаются отключенными.

Версия 1 поддерживает только действия для чтения одного файла в файловом менеджере.
