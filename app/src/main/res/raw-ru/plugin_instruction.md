Используйте HTML Previewer в файловом менеджере:

1. Установите и включите плагин `HTML Previewer`.
2. Откройте дополнительное меню поддерживаемого файла HTML или MHTML.
3. Выберите `Предпросмотр HTML`.

Плагин получает временный доступ на чтение выбранного файла и его родительского каталога через URI содержимого. Он не получает исходный путь файловой системы.

Поддерживаемые расширения: `html`, `htm`, `shtm`, `shtml`, `xht`, `xhtml`, `mht`, `mhtml`.

Для MHTML средство просмотра выбирает корневую часть HTML и связывает разрешенные встроенные стили, изображения, шрифты, аудио и видео с изолированным виртуальным источником. Расположения и ID содержимого служат только внутренними метками; неоднозначные метки игнорируются, а на устройство ничего не распаковывается.

По умолчанию скрипты отключены. Для доверенного полного обычного HTML включите интерактивный режим в настройках: JavaScript, кнопки, WebGL и локальное хранилище. В MHTML, усечённом HTML, исходном коде и экспорте PDF скрипты всегда отключены. Cookie, прямой доступ к файлам/content, нативные JavaScript-мосты и новые окна остаются отключены. Локальное хранилище для настроек и счёта доступно лишь в интерактивном режиме. Исходный код и PDF используют заново очищенное содержимое.

Средство просмотра также поддерживает поиск по странице, настройку размера текста и выбор темы. Оно распознает BOM, кодировку MIME и ранние объявления кодировки HTML. Для обычного HTML больше 8 MB требуется подтверждение, после чего показываются первые 8 MB с отметкой усечения; MHTML должен быть полным и при превышении 8 MB отклоняется.

Выберите `Показать исходный код` в меню, чтобы просмотреть исходный текст только для чтения моноширинным шрифтом, а затем `Показать предпросмотр`, чтобы вернуться. В этом режиме теги остаются обычным текстом, а все исходящие запросы блокируются.

Локальные ресурсы читаются из разрешённого каталога или выбранного MHTML. Безопасный режим разрешает публичные HTTPS-изображения; интерактивный также разрешает публичные HTTPS-скрипты, стили и запросы при включённых сетевых ресурсах. Отключение сети блокирует исходящие запросы WebView. Скрипты могут отправлять данные страницы удалённым сервисам; включайте режим только для доверенных страниц.

Выберите `Экспорт в PDF`, чтобы открыть системную панель печати Android с заново прочитанной, очищенной копией в светлой теме. Это действует и при экспорте из просмотра исходного кода, не меняя текущее состояние окна. Выберите `Сохранить как PDF` и место назначения в системном интерфейсе; плагин не запрашивает разрешение на хранилище.

Explorer Action v2 поддерживает основную кнопку и контекстное меню одного файла с временным доступом на чтение документа и родительского каталога. Требуется AutoJs6 build 5269 или новее.

Меню и диалоги используют язык и тёмный режим AutoJs6, как и GitHub (Auto) и автоматическая тема HTML. Панели получают представительный цвет краёв страницы и контрастные чёрные или белые надписи и значки. Для градиентов, изображений и анимации цвет сохраняется до перезагрузки, исключая мерцание.
