HTML Previewer 在 AutoJs6 中预览 HTML 与 MHTML 文件, 不需要打开浏览器. 页面默认以安全模式显示, 不运行脚本; 还可以查看源码, 在页面中查找, 或导出为 PDF. 预览全程只读, 不修改原文件.

### 开始使用

1. 在 AutoJs6 的 "插件中心" 中确认本插件已启用.
2. 打开 AutoJs6 的文件管理器, 找到要预览的 HTML 或 MHTML 文件.
3. 在文件菜单中选择 "预览 HTML" (AutoJs6 6.8.1 及以上版本中位于一级菜单 "HTML Previewer" 之下).
4. 在预览页右上角的菜单中使用查找, 查看源码, 导出 PDF 与 "设置" 等功能.

### 主要功能

- **在页面中查找**: 输入关键词后高亮匹配项, 并可在匹配项之间跳转.
- **查看源码**: 以只读的等宽排版显示原始文本, 选择 "查看预览" 即可返回页面.
- **导出 PDF**: 打开系统打印界面, 在其中选择保存为 PDF 及保存位置; 插件不需要存储权限.
- **交互模式**: 在 "设置" 中开启后可运行脚本, 让按钮, 动画与本地存储生效; 每次新预览都会自动关闭, 请只对可信页面开启.
- **网络资源**: 开启 "加载网络图片" 后可显示 HTTPS 图片; 开启交互模式时此项变为 "加载网络资源", 还允许 HTTPS 脚本与样式.
- **字号与主题**: 在 "设置" 中调整 "字号", 主题可选 "跟随 AutoJs6", "浅色" 或 "深色".
- **全屏模式**: 隐藏工具栏, 专注阅读; 开启 "以全屏模式启动" 后每次预览都直接进入全屏.
- **MHTML 归档**: 显示网页归档中的页面及其嵌入的样式, 图片与字体, 不会把内容解压到存储空间.

### 运行要求

- Android 7.0 或更高版本.
- AutoJs6 6.8.0 或更高版本.
- 不需要存储权限; 插件只读取所选文件及其所在目录, 网络只用于加载 HTTPS 资源.

### 常见问题

**按钮与动画没有反应的原因**

页面默认不运行脚本. 对于可信的完整 HTML 文件, 可在 "设置" 中开启 "交互模式". MHTML 文件, 只显示了前一部分的大文件与源码视图始终不运行脚本.

**部分图片或样式没有显示的原因**

本地图片与样式需要位于 HTML 文件所在的目录或其子目录中. 网络图片需要开启 "加载网络图片", 并且只支持 HTTPS 地址.

**大文件只显示前一部分的原因**

超过 8 MB 的 HTML 文件会先询问, 确认后只显示前 8 MB 并标出截断位置. MHTML 归档必须完整显示, 超过 8 MB 时无法预览.

**文件菜单中没有 "预览 HTML" 的原因**

本插件只处理扩展名为 html, htm, shtm, shtml, xht, xhtml, mht, mhtml 的文件. 请确认文件的扩展名, 并在 "插件中心" 中确认本插件已启用.
