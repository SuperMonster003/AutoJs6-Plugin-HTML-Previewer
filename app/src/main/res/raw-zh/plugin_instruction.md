在文件管理器中使用 HTML Previewer:

1. 安装并启用 `HTML Previewer` 插件.
2. 打开一个受支持 HTML 或 MHTML 文件的溢出菜单.
3. 选择 `预览 HTML`.

插件通过 content URI 临时获得所选文件及其父目录的读取权限. 插件不会接收原始文件系统路径.

支持的扩展名: `html`, `htm`, `shtm`, `shtml`, `xht`, `xhtml`, `mht`, `mhtml`.

对于 MHTML, 查看器会选择归档的 HTML 根部件, 并把类型允许的嵌入样式, 图片, 字体, 音频和视频映射到隔离的虚拟源. 归档位置与内容 ID 只作为内部标签; 歧义标签会被忽略, 任何内容都不会解压到存储空间.

默认禁用脚本. 对于可信的完整普通 HTML 文件, 可在 `设置` 中开启 `交互模式`, 支持 JavaScript, 按钮事件, WebGL 和本地存储. MHTML, 截断 HTML, 源码视图和 PDF 导出始终禁用脚本. Cookie, 直接文件/content 访问, 原生 JavaScript 桥和新窗口保持禁用. 安全模式禁用页面存储; 交互模式允许本地存储, 用于页面偏好或游戏分数. 源码视图与 PDF 使用重新净化的内容.

查看器还支持页内查找, 字号调节和主题选择. 它能识别 BOM, MIME 字符集与文件前部的 HTML 编码声明. 超过 8 MB 的普通 HTML 需确认后才会仅显示前 8 MB 并标出截断位置; MHTML 必须保持完整, 超过 8 MB 时会被拒绝.

可在查看器菜单中选择 `查看源码`, 以只读等宽排版检查原始文本, 再选择 `查看预览` 返回. 源码模式下标签始终按原文显示, 并会封锁全部出站请求.

本地资源来自已授权目录或选中的 MHTML 归档. 安全模式允许公共 HTTPS 图片; 交互模式开启 `加载网络资源` 后还允许公共 HTTPS 脚本, 样式及请求. 关闭网络开关会拦截 WebView 出站请求. 交互脚本能够向远程服务发送页面数据, 因此仅应对可信页面启用.

选择 `导出 PDF` 会使用重新读取, 净化并强制浅色的副本打开 Android 系统打印界面. 从源码视图发起时也遵循相同流程, 且不会改变当前查看器状态. 请在系统界面中选择 `保存为 PDF` 及目标位置; 插件不申请存储权限.

Explorer Action v2 同时支持单文件的主预览按钮和溢出菜单, 通过临时只读授权访问文档及其父目录. 需要 AutoJs6 构建 5269 或更高版本.

菜单和对话框跟随 AutoJs6 的语言与暗色模式. GitHub (Auto) 和 HTML 自动主题也跟随 AutoJs6. 工具栏及系统栏使用渲染页面边缘的代表色, 配合有对比度的黑色或白色文字与图标. 渐变, 图片和动画背景取色后保持稳定, 重新加载时更新, 避免闪烁.
