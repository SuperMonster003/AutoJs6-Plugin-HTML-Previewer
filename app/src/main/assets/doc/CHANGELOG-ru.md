# v1.1.0

###### 2026/09/13

* `Функция` Локальная история выпусков в интерфейсе с переводами и английским запасным вариантом
* `Исправление` Статический просмотр и управляемый HTTPS-клиент проверяют публичные DNS-адреса, фиксируют их для соединения и проверяют каждое перенаправление. Настройка ресурсов управляет этим клиентом, поддерживающим только GET и HEAD.
* `Исправление` Включайте только для текущего доверенного документа. WebRTC и другие API могут обращаться к сети независимо от настройки ресурсов. Каждый новый просмотр отключает скрипты.
* `Исправление` Сохранение HTTP 206 и других успешных кодов при загрузке удаленных ресурсов
* `Улучшение` Проверка полной настройки подписи, ожидаемого набора APK и воспроизводимости документации
* `Зависимость` Добавление OkHttp 4.12.0 для контролируемой загрузки ресурсов HTTPS

# v1.0.1

###### 2026/09/11

* `Функция` По умолчанию скрипты отключены. Для доверенного полного обычного HTML включите интерактивный режим в настройках: JavaScript, кнопки, WebGL и локальное хранилище. В MHTML, усечённом HTML, исходном коде и экспорте PDF скрипты всегда отключены.
* `Исправление` Ошибка, из-за которой включение плагина в центре плагинов могло завершаться сбоем
* `Исправление` Исправлены отказ протокола основной кнопки и сбои настроек; синхронизированы оформление AutoJs6, цвета панелей и монохромные элементы диалогов
* `Улучшение` Более лаконичные название и описание плагина, более понятная пользовательская документация
* `Улучшение` Проверка сборки отклоняет непреднамеренные нативные зависимости и создает отчет JSON

# v1.0.0

###### 2026/08/06

* `Функция` Первый выпуск: действие меню `Предпросмотр HTML` для файлов HTML в файловом менеджере AutoJs6 (ID плагина `html-previewer`)
* `Функция` Безопасное средство просмотра: скрипты, фреймы, встроенные объекты и отправка форм удаляются перед показом, все работает только для чтения и без выполнения JavaScript
* `Функция` Загрузка ресурсов: поддерживаются стили страницы, локальные ресурсы рядом с файлом и веб-изображения HTTPS по контролируемым правилам, все прочие запросы блокируются
* `Функция` Комфорт чтения: автоматическая светлая/темная тема, масштабирование щипком, обновление, полноэкранный режим и настройка `Запускать в полноэкранном режиме`
* `Функция` Границы безопасности: принимается только временное разрешение на чтение от хоста, размер файла ограничен 8 MB, имена файлов и пути ресурсов строго проверяются
* `Функция` Многоязычность: интерфейс, инструкции, README и changelog на 10 языках
