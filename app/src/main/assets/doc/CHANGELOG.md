### 发行历史

# v1.1.3

###### 2026/09/19

* `修复` 页面背景已渲染但状态栏及导航栏颜色仍需等待 JavaScript 加载后才更新的问题
* `修复` AGP 9.1 构建时的 SDK XML v4 解析警告, 以及 JVM 单元测试误触发 APK 原生库对齐检查的问题 (共享构建插件 1.8.3)

###### 2026/09/16

* `优化` targetSdk 升级至 37 (Android 17)

# v1.1.1

###### 2026/09/15

* `优化` compileSdk 升级至 37 (Android 17), targetSdk 保持 36

# v1.1.0

###### 2026/09/13

* `新增` 发行历史页面, 支持多语言显示及英文回退
* `修复` 静态预览及 HTTPS 资源加载的 DNS 地址校验不足的问题, 每次重定向重新校验公网地址 (资源开关仅控制该客户端, 请求限 GET/HEAD)
* `修复` 交互模式的脚本启用范围限制为当前可信文档, 新预览默认关闭脚本 (WebRTC 等脚本联网方式不受远程资源开关控制)
* `修复` 远程资源加载未保留 HTTP 206 等成功状态码的问题
* `优化` 完善发行签名, APK 变体及生成文档一致性校验
* `依赖` 附加 OkHttp 版本 4.12.0, 用于受控 HTTPS 资源加载

# v1.0.1

###### 2026/09/11

* `新增` 设置页增加 "交互模式", 为可信的完整 HTML 文件启用 JavaScript, 按钮事件, WebGL 及本地存储 (默认关闭, MHTML/截断 HTML/源码视图/PDF 导出始终禁用脚本)
* `修复` 在插件中心启用插件时可能提示启用失败的问题
* `修复` 主预览按钮请求被拒绝, 设置页崩溃及部分界面未跟随宿主外观的问题
* `优化` 更简洁的插件名称与描述, 更易读的使用文档
* `优化` 构建阶段阻止意外引入原生依赖, 并输出 JSON 校验报告

# v1.0.0

###### 2026/08/06

* `新增` AutoJs6 文件管理器的 HTML 文件增加 "预览 HTML" 菜单
* `新增` 安全查看器: 显示前自动移除脚本, 框架, 嵌入对象与表单提交, 全程只读且不执行 JavaScript
* `新增` 资源加载: 支持页面样式, 同目录本地资源与 HTTPS 网络图片的受控加载, 其余请求一律拦截
* `新增` 阅读体验: 深色/浅色主题自适应, 双指缩放, 刷新, 全屏模式与 "以全屏模式启动" 设置
* `新增` 安全边界: 仅接受宿主授予的临时读取权限, 单文件上限 8 MB, 严格校验文件名与资源路径
* `新增` 多语言: 界面, 使用说明, README 与更新日志支持 10 种语言
