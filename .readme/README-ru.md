### Введение

******

Просмотр в одно касание: открывайте веб-файлы прямо из файлового менеджера через меню `Предпросмотр HTML` - без браузера, а для чисто локальных страниц и без сети.

По умолчанию скрипты отключены. Для доверенного полного обычного HTML включите интерактивный режим в настройках: JavaScript, кнопки, WebGL и локальное хранилище. В MHTML, усечённом HTML, исходном коде и экспорте PDF скрипты всегда отключены.

******

### Основные возможности

******

- Просмотр в одно касание: открывайте веб-файлы прямо из файлового менеджера через меню `Предпросмотр HTML` - без браузера, а для чисто локальных страниц и без сети.
- По умолчанию скрипты отключены. Для доверенного полного обычного HTML включите интерактивный режим в настройках: JavaScript, кнопки, WebGL и локальное хранилище. В MHTML, усечённом HTML, исходном коде и экспорте PDF скрипты всегда отключены.
- Безопасный просмотр исходного кода: переключайтесь между очищенным предпросмотром и исходным HTML только для чтения; для MHTML показывается декодированный корневой HTML, теги остаются обычным текстом, а режим не отправляет сетевых запросов.
- Системный экспорт PDF: выберите `Экспорт в PDF`, чтобы передать заново очищенную копию со светлой темой в панель печати Android; параметры страниц и `Сохранить как PDF` обрабатывает система без разрешения на хранилище.
- Точная верстка: поддерживаются стили и разрешенные ресурсы внутри MHTML, локальные ресурсы рядом с обычным HTML (изображения, шрифты, аудио, видео) и необязательные веб-изображения по HTTPS, которые можно полностью отключить.
- Комфортное чтение: поиск по странице, размер текста 75%-200%, масштабирование щипком и автоматическая, светлая или темная тема. Меню и диалоги используют язык и тёмный режим AutoJs6, как и GitHub (Auto) и автоматическая тема HTML. Панели получают представительный цвет краёв страницы и контрастные чёрные или белые надписи и значки. Для градиентов, изображений и анимации цвет сохраняется до перезагрузки, исключая мерцание.
- Полноэкранный режим: в любой момент переключайтесь в иммерсивный полноэкранный режим или включите `Запускать в полноэкранном режиме` в настройках.
- Внешние ссылки: нажатие на ссылку http/https передается системному браузеру, а переходы по якорям внутри страницы продолжают работать.
- Многоязычность: интерфейс, инструкции, README и changelog доступны на 10 языках.

### Как пользоваться

******

1. Скачайте свежий APK плагина со страницы [Releases](https://github.com/SuperMonster003/AutoJs6-Plugin-HTML-Previewer/releases) и установите его на устройство.
2. Откройте центр плагинов AutoJs6 и включите плагин `Просмотр HTML`.
3. В файловом менеджере AutoJs6 найдите нужный файл HTML или MHTML и откройте его дополнительное меню (дополнительные действия).
4. Выберите `Предпросмотр HTML` - страница откроется в отдельном средстве просмотра.
5. Во время чтения меню в правом верхнем углу позволяет искать текст, переключаться между `Показать исходный код` и `Показать предпросмотр`, выполнить `Экспорт в PDF` или `Обновить`, переключить `Полноэкранный режим` либо открыть `Настройки` для выбора размера текста, темы, сетевых изображений и запуска во весь экран; кнопка Назад закрывает поиск, полноэкранный режим или просмотр.

> Если плагин не появился в центре плагинов, сначала обновите AutoJs6 до свежей версии (внутренняя сборка 5269 или новее). Explorer Action v2 поддерживает основную кнопку и контекстное меню одного файла с временным доступом на чтение документа и родительского каталога. Требуется AutoJs6 build 5269 или новее.

### Поддерживаемые форматы

******

Плагин распознает следующие расширения, а также файлы без расширения, явно отмеченные хостом как `text/html`, `application/xhtml+xml`, `multipart/related` или `application/x-mimearchive`:

```text
html, htm, shtm, shtml, xht, xhtml, mht, mhtml
```

Файлы до 8 MB загружаются полностью. Для обычного HTML большего размера после подтверждения можно показать первые 8 MB с отметкой усечения; MHTML должен быть полным и при превышении лимита отклоняется. При декодировании HTML используются по порядку BOM, кодировка MIME, раннее объявление `meta charset` или `http-equiv`, затем UTF-8. MHTML поддерживает ограниченную вложенность MIME и кодировки передачи identity, quoted-printable и Base64.

### Частые вопросы

******

#### Почему кнопки и динамические эффекты на странице не работают?

По умолчанию скрипты отключены. Для доверенного полного обычного HTML включите интерактивный режим в настройках: JavaScript, кнопки, WebGL и локальное хранилище. В MHTML, усечённом HTML, исходном коде и экспорте PDF скрипты всегда отключены.

#### Почему некоторые изображения или стили не отображаются?

Локальные ресурсы читаются из разрешённого каталога или выбранного MHTML. Безопасный режим разрешает публичные HTTPS-изображения; интерактивный также разрешает публичные HTTPS-скрипты, стили и запросы при включённых сетевых ресурсах. Отключение сети блокирует исходящие запросы WebView. Скрипты могут отправлять данные страницы удалённым сервисам; включайте режим только для доверенных страниц.

#### Предпросмотр выглядит не совсем как в браузере. Это нормально?

В безопасном режиме по умолчанию: Да. Помимо удаления скриптов средство просмотра добавляет базовый стиль для чтения и отключает некоторые продвинутые возможности. Цель - безопасное и удобное чтение, а не попиксельное совпадение. Итоговый вид проверяйте в браузере.

#### Плагин куда-нибудь загружает мои файлы?

Локальные ресурсы читаются из разрешённого каталога или выбранного MHTML. Безопасный режим разрешает публичные HTTPS-изображения; интерактивный также разрешает публичные HTTPS-скрипты, стили и запросы при включённых сетевых ресурсах. Отключение сети блокирует исходящие запросы WebView. Скрипты могут отправлять данные страницы удалённым сервисам; включайте режим только для доверенных страниц.

#### Куда сохраняется экспортированный PDF?

`Экспорт в PDF` открывает системную панель печати Android. Выберите `Сохранить как PDF`, затем укажите имя и место в системном выборе файлов. Плагин не записывает данные прямо в хранилище и не запрашивает разрешение на него. Экспорт всегда заново читает HTML или полный MHTML и очищает корневую страницу, даже если запущен из просмотра исходного кода, и не меняет текущее состояние окна.

#### Можно ли редактировать файлы HTML или просматривать целый сайт?

Текущая версия ограничена просмотром одного файла только для чтения: редактирования нет, обход каталогов не выполняется. Ресурсы рядом с файлом читаются по мере необходимости, а плагин владеет лишь временным разрешением на чтение, выданным хостом. Планы описаны в [ROADMAP.md](https://github.com/SuperMonster003/AutoJs6-Plugin-HTML-Previewer/blob/master/ROADMAP.md).

### Разрешения и безопасность

******

Интерактивный режим отключен для каждого нового просмотра и требует явного включения для текущего доверенного документа. CSP блокирует fetch, WebSocket, worker и фреймы. Интерактивный JavaScript не является универсальной сетевой песочницей: WebRTC может работать независимо от настройки ресурсов. Незнакомые документы открывайте в статическом режиме по умолчанию.

- В безопасном режиме по умолчанию: Очистка перед показом: удаляются скрипты, атрибуты обработчиков событий, встроенные фреймы, встроенные объекты и адреса отправки форм, а небезопасные адреса ссылок и ресурсов отфильтровываются.
- Cookie, прямой доступ к файлам/content, нативные JavaScript-мосты и новые окна остаются отключены. Локальное хранилище для настроек и счёта доступно лишь в интерактивном режиме. Исходный код и PDF используют заново очищенное содержимое.
- Интерактивный режим отключен для каждого нового просмотра и требует явного включения для текущего доверенного документа. CSP блокирует fetch, WebSocket, worker и фреймы. Интерактивный JavaScript не является универсальной сетевой песочницей: WebRTC может работать независимо от настройки ресурсов. Незнакомые документы открывайте в статическом режиме по умолчанию.
- Минимум привилегий: плагин получает только временное разрешение на чтение по URI содержимого от хоста, не видит путей файловой системы и передает PDF системной службе печати Android вместо самостоятельной записи в хранилище.
- Ограниченный ввод: чтение ограничено 8 MB; для MHTML также ограничены число частей, вложенность, заголовки и объем декодирования; имена файлов и пути ресурсов строго проверяются, чтобы исключить выход за допустимые границы.
- Включайте только для текущего доверенного документа. WebRTC и другие API могут обращаться к сети независимо от настройки ресурсов. Каждый новый просмотр отключает скрипты.
- Статический просмотр и управляемый HTTPS-клиент проверяют публичные DNS-адреса, фиксируют их для соединения и проверяют каждое перенаправление. Настройка ресурсов управляет этим клиентом, поддерживающим только GET и HEAD.

В безопасном режиме по умолчанию: Исходный манифест запрашивает только разрешение на сеть (используется, когда включены HTTPS-изображения) и разрешение плагина AutoJs6. AndroidX также добавляет ограниченное пакетом разрешение уровня подписи для защиты неэкспортируемых динамических приемников; доступа к данным устройства оно не дает. При отключенных сетевых изображениях WebView не выполняет исходящих запросов. Доступ к месту назначения PDF обеспечивают системные окна печати и выбора файлов Android, поэтому разрешения на хранилище, мультимедиа, камеру, геолокацию и другие чувствительные разрешения не запрашиваются.

### Интерфейс плагина

******

Следующая информация предназначена для разработчиков; хост обнаруживает и запускает плагин по этим идентификаторам:

```text
application id: io.github.supermonster003.autojs6.plugin.htmlpreviewer
service action: org.autojs.plugin.EXPLORER_ACTION
execute action: org.autojs.plugin.EXPLORER_ACTION_EXECUTE
plugin id: html-previewer
engine: explorer-action
variant: default
protocol version: 2
minimum host build: 5269
audited host build: 5279
audited host protocol: 22
```

Explorer Action v2 поддерживает основную кнопку и контекстное меню одного файла с временным доступом на чтение документа и родительского каталога. Требуется AutoJs6 build 5269 или новее.

- [Открыть матрицу совместимости Explorer Action](https://github.com/SuperMonster003/AutoJs6-Plugin-HTML-Previewer/blob/master/docs/explorer-action-compatibility.md)

### Локализация и генерация документов

******

```text
.readme/common.json
.readme/lang_*.json
.readme/template_readme.md
.changelog/lang_*.json
.changelog/template_changelog.md
.python/generate_markdown.py
app/src/main/assets/doc/CHANGELOG-*.md
app/src/main/res/values-*/strings.xml
app/src/main/res/raw-*/plugin_instruction.md
```

`strings.xml` локализует сведения о плагине и интерфейс средства просмотра, а `plugin_instruction.md` содержит инструкции, отображаемые хостом. README и changelog всегда правятся через JSON-источники в `.readme/` и `.changelog/` с последующим запуском `py .python/generate_markdown.py`; сгенерированные файлы вручную не редактируются. Команда `py .python/generate_markdown.py --check` проверяет синхронность источников и сгенерированных файлов.
