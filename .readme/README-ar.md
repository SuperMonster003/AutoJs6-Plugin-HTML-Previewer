### مقدمة

******

معاينة بلمسة واحدة: افتح ملفات الويب مباشرة من مدير الملفات عبر قائمة `معاينة HTML`, من دون متصفح ومن دون شبكة للصفحات المحلية الصرفة.

تكون البرامج النصية معطلة افتراضيا. لملف HTML عادي كامل وموثوق, فعّل الوضع التفاعلي في الإعدادات لتشغيل JavaScript وأحداث الأزرار وWebGL والتخزين المحلي. تبقى النصوص معطلة دائما في MHTML وHTML المقتطع وعرض المصدر وتصدير PDF.

******

### أبرز الميزات

******

- معاينة بلمسة واحدة: افتح ملفات الويب مباشرة من مدير الملفات عبر قائمة `معاينة HTML`, من دون متصفح ومن دون شبكة للصفحات المحلية الصرفة.
- تكون البرامج النصية معطلة افتراضيا. لملف HTML عادي كامل وموثوق, فعّل الوضع التفاعلي في الإعدادات لتشغيل JavaScript وأحداث الأزرار وWebGL والتخزين المحلي. تبقى النصوص معطلة دائما في MHTML وHTML المقتطع وعرض المصدر وتصدير PDF.
- عرض مصدر آمن: بدّل بين المعاينة المنقاة وHTML الأصلي للقراءة فقط; يعرض MHTML صفحة HTML الجذرية بعد فك ترميزها, وتبقى الوسوم نصا حرفيا ولا يرسل وضع المصدر أي طلبات شبكة.
- تصدير PDF عبر النظام: اختر `تصدير PDF` لإرسال نسخة منقاة من جديد وبسمة فاتحة إلى لوحة الطباعة في Android; يتولى النظام إعدادات الصفحات وخيار `حفظ كملف PDF` من دون إذن تخزين.
- تنسيق أمين: يدعم الأنماط والموارد المسموح بها داخل MHTML, والموارد المحلية المجاورة لملف HTML العادي (صور وخطوط وصوت وفيديو), إضافة إلى صور الويب الاختيارية عبر HTTPS التي يمكن تعطيلها تماما.
- قراءة مريحة: بحث داخل الصفحة, وحجم نص 75%-200%, وتكبير بإصبعين, وسمات AutoJs6 أو الفاتحة أو الداكنة. تتبع القوائم والحوارات لغة AutoJs6 والوضع الداكن, وكذلك GitHub (Auto) وسمة HTML التلقائية. تستخدم الأشرطة لونا ممثلا لحواف الصفحة مع نصوص وأيقونات سوداء أو بيضاء متباينة. يبقى اللون ثابتا حتى إعادة التحميل مع التدرجات والصور والرسوم المتحركة لتجنب الوميض.
- وضع ملء الشاشة: انتقل في أي وقت إلى ملء الشاشة الغامر, أو فعل `البدء في وضع ملء الشاشة` من الإعدادات.
- الروابط الخارجية: عند النقر على رابط http/https يسلم إلى متصفح النظام, بينما تظل روابط الارتساء داخل الصفحة تعمل.
- متعدد اللغات: الواجهة والتعليمات و README وسجل التغييرات متوفرة بعشر لغات.

### طريقة الاستخدام

******

1. نزل أحدث APK للملحق من صفحة [Releases](https://github.com/SuperMonster003/AutoJs6-Plugin-HTML-Previewer/releases) وثبته على الجهاز.
2. افتح مركز الملحقات في AutoJs6 وفعل ملحق `معاينة HTML`.
3. في مدير الملفات في AutoJs6 حدد ملف HTML أو MHTML الذي تريد عرضه وافتح قائمته الإضافية (إجراءات إضافية).
4. اختر `معاينة HTML` فتفتح الصفحة في عارض مخصص.
5. أثناء القراءة استخدم القائمة العلوية للبحث عن النص والتبديل بين `عرض المصدر` و`عرض المعاينة` أو `تصدير PDF` أو تنفيذ `تحديث` أو تبديل `وضع ملء الشاشة`, وافتح `الإعدادات` لضبط حجم النص والسمة وصور الشبكة والبدء بملء الشاشة; زر الرجوع يغلق البحث أو ملء الشاشة أو العارض.

> إذا لم يظهر الملحق في مركز الملحقات فحدث AutoJs6 أولا إلى إصدار حديث (البنية الداخلية 5269 أو أحدث). يدعم Explorer Action v2 زر العرض الرئيسي وقائمة الملف الواحد مع إذن قراءة مؤقت للمستند والمجلد الأب. يلزم AutoJs6 بالإصدار الداخلي 5269 أو أحدث.

### التنسيقات المدعومة

******

يتعرف الملحق على الامتدادات التالية, وعلى الملفات بلا امتداد التي يحددها المضيف صراحة كـ `text/html` أو `application/xhtml+xml` أو `multipart/related` أو `application/x-mimearchive`:

```text
html, htm, shtm, shtml, xht, xhtml, mht, mhtml
```

تحمل الملفات حتى 8 MB كاملة. يمكن عرض أول 8 MB من HTML العادي الأكبر بعد التأكيد مع تحديد موضع الاقتطاع; أما MHTML فيجب أن يبقى كاملا ويرفض عند تجاوز الحد. عند فك HTML تستخدم بالترتيب BOM ثم مجموعة محارف MIME ثم إعلان `meta charset` أو `http-equiv` المبكر ثم UTF-8. يدعم MHTML تداخلا محدودا لأجزاء MIME وترميزات النقل identity وquoted-printable وBase64.

### الأسئلة الشائعة

******

#### لماذا لا تستجيب الأزرار والتأثيرات الديناميكية في الصفحة?

تكون البرامج النصية معطلة افتراضيا. لملف HTML عادي كامل وموثوق, فعّل الوضع التفاعلي في الإعدادات لتشغيل JavaScript وأحداث الأزرار وWebGL والتخزين المحلي. تبقى النصوص معطلة دائما في MHTML وHTML المقتطع وعرض المصدر وتصدير PDF.

#### لماذا لا تظهر بعض الصور أو الأنماط?

تُقرأ الموارد المحلية من المجلد المصرح به أو أرشيف MHTML المحدد. يسمح الوضع الآمن بصور HTTPS العامة, ويسمح الوضع التفاعلي أيضا بالنصوص والأنماط والطلبات العامة عبر HTTPS عند تفعيل موارد الشبكة. يؤدي تعطيل الشبكة إلى حظر طلبات WebView الصادرة. تستطيع النصوص التفاعلية إرسال بيانات الصفحة إلى خدمات بعيدة, لذا فعّلها للصفحات الموثوقة فقط.

#### المعاينة لا تطابق عرض المتصفح تماما, هل هذا طبيعي?

في الوضع الآمن الافتراضي: نعم. فإلى جانب إزالة البرامج النصية يضيف العارض نمط قراءة أساسيا ويعطل بعض الخصائص المتقدمة. الهدف قراءة آمنة وواضحة لا مطابقة بكسلية. للتحقق من المظهر النهائي استخدم المتصفح.

#### هل يرفع هذا الملحق ملفاتي إلى أي مكان?

تُقرأ الموارد المحلية من المجلد المصرح به أو أرشيف MHTML المحدد. يسمح الوضع الآمن بصور HTTPS العامة, ويسمح الوضع التفاعلي أيضا بالنصوص والأنماط والطلبات العامة عبر HTTPS عند تفعيل موارد الشبكة. يؤدي تعطيل الشبكة إلى حظر طلبات WebView الصادرة. تستطيع النصوص التفاعلية إرسال بيانات الصفحة إلى خدمات بعيدة, لذا فعّلها للصفحات الموثوقة فقط.

#### أين يحفظ ملف PDF المصدر?

يفتح `تصدير PDF` لوحة الطباعة في نظام Android. اختر `حفظ كملف PDF`, ثم حدد اسم الملف ومكانه في منتقي الملفات التابع للنظام. لا يكتب الملحق مباشرة إلى التخزين ولا يطلب إذنه. يعيد التصدير دائما قراءة HTML أو أرشيف MHTML الكامل وينقي الصفحة الجذرية حتى عند بدئه من عرض المصدر, ولا يغير حالة العارض الحالية.

#### هل يمكن تحرير ملفات HTML أو معاينة موقع ويب كامل?

الإصدار الحالي مخصص لمعاينة ملف واحد للقراءة فقط: لا توجد إمكانية تحرير ولا استعراض للمجلدات. تقرأ الموارد المجاورة للملف عند الحاجة فقط, ولا يملك الملحق سوى إذن القراءة المؤقت الذي يمنحه المضيف. راجع [ROADMAP.md](https://github.com/SuperMonster003/AutoJs6-Plugin-HTML-Previewer/blob/master/ROADMAP.md) للاطلاع على الخطط.

### الأذونات والأمان

******

يفترض الملحق أن الملف المعاين غير موثوق ويطبق طبقات حماية متعددة:

- في الوضع الآمن الافتراضي: تنقية قبل العرض: تحذف البرامج النصية وسمات معالجات الأحداث والإطارات المضمنة والكائنات المضمنة ووجهات النماذج, وترشح عناوين الروابط والموارد غير الآمنة.
- تبقى ملفات الارتباط والوصول المباشر إلى الملفات/content وجسور JavaScript الأصلية والنوافذ الجديدة معطلة. يسمح الوضع التفاعلي فقط بالتخزين المحلي للتفضيلات ونتائج الألعاب. يستخدم المصدر وPDF محتوى منقحا من جديد.
- تُقرأ الموارد المحلية من المجلد المصرح به أو أرشيف MHTML المحدد. يسمح الوضع الآمن بصور HTTPS العامة, ويسمح الوضع التفاعلي أيضا بالنصوص والأنماط والطلبات العامة عبر HTTPS عند تفعيل موارد الشبكة. يؤدي تعطيل الشبكة إلى حظر طلبات WebView الصادرة. تستطيع النصوص التفاعلية إرسال بيانات الصفحة إلى خدمات بعيدة, لذا فعّلها للصفحات الموثوقة فقط.
- أدنى الامتيازات: لا يتلقى الملحق سوى إذن قراءة مؤقت عبر content URI يمنحه المضيف, ولا يرى مسارات نظام الملفات; ويرسل مخرجات PDF عبر خدمة الطباعة في Android بدلا من الكتابة إلى التخزين بنفسه.
- إدخال محدود: تقتصر القراءة على 8 MB; ويحد MHTML أيضا عدد الأجزاء وعمق التداخل والرؤوس وإجمالي البيانات المفكوكة; وتخضع أسماء الملفات ومسارات الموارد لتحقق صارم يمنع الوصول خارج النطاق.
- تبقى ملفات الارتباط والوصول المباشر إلى الملفات/content وجسور JavaScript الأصلية والنوافذ الجديدة معطلة. يسمح الوضع التفاعلي فقط بالتخزين المحلي للتفضيلات ونتائج الألعاب. يستخدم المصدر وPDF محتوى منقحا من جديد.

في الوضع الآمن الافتراضي: لا يطلب بيان المصدر سوى إذن الشبكة (يستخدم عند تفعيل صور HTTPS) وإذن ملحقات AutoJs6. يضيف AndroidX أيضا إذن توقيع خاصا بحزمة التطبيق لحماية أجهزة الاستقبال الديناميكية غير المصدرة, ولا يمنح وصولا إلى بيانات الجهاز. عند تعطيل صور الشبكة لا يصدر WebView أي طلب خارجي. يتولى نظام Android للطباعة ومنتقي الملفات الوصول إلى وجهة PDF, لذلك لا يطلب الملحق أذونات التخزين أو الوسائط أو الكاميرا أو الموقع أو غيرها من الأذونات الحساسة.
