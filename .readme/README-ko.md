### 소개

******

원탭 미리보기: 파일 관리자의 `HTML 미리보기` 메뉴로 웹 파일을 바로 열 수 있으며, 브라우저가 필요 없고 순수 로컬 페이지라면 네트워크도 필요 없습니다.

스크립트는 기본적으로 비활성화됩니다. 신뢰할 수 있는 완전한 일반 HTML 파일에서는 설정의 상호작용 모드를 켜면 JavaScript, 버튼 이벤트, WebGL, 로컬 저장소를 사용할 수 있습니다. MHTML, 잘린 HTML, 소스 보기, PDF 내보내기는 항상 스크립트를 비활성화합니다.

******

### 주요 기능

******

- 원탭 미리보기: 파일 관리자의 `HTML 미리보기` 메뉴로 웹 파일을 바로 열 수 있으며, 브라우저가 필요 없고 순수 로컬 페이지라면 네트워크도 필요 없습니다.
- 스크립트는 기본적으로 비활성화됩니다. 신뢰할 수 있는 완전한 일반 HTML 파일에서는 설정의 상호작용 모드를 켜면 JavaScript, 버튼 이벤트, WebGL, 로컬 저장소를 사용할 수 있습니다. MHTML, 잘린 HTML, 소스 보기, PDF 내보내기는 항상 스크립트를 비활성화합니다.
- 안전한 소스 보기: 정리된 미리보기와 읽기 전용 원본 HTML 사이를 전환할 수 있습니다. MHTML은 디코딩한 루트 HTML을 표시하며 태그는 문자 그대로 유지되고 네트워크 요청을 전혀 보내지 않습니다.
- 시스템 PDF 내보내기: `PDF 내보내기`를 선택하면 다시 정리하고 밝은 테마로 고정한 사본을 Android 인쇄 화면으로 보냅니다. 페이지 설정과 `PDF로 저장`은 시스템이 처리하므로 저장소 권한이 필요 없습니다.
- 레이아웃 재현: 페이지 자체 스타일, MHTML에 포함된 허용 리소스, 일반 HTML과 같은 디렉터리의 이미지, 글꼴, 오디오, 동영상 및 완전히 끌 수 있는 HTTPS 웹 이미지를 지원합니다.
- 편안한 읽기: 페이지 내 검색, 75%-200% 글자 크기, 두 손가락 확대/축소, 시스템/라이트/다크 테마를 지원합니다. 메뉴와 대화상자는 AutoJs6 언어와 다크 모드를 따릅니다. GitHub (Auto)와 HTML 자동 테마도 동일합니다. 도구 모음과 시스템 표시줄은 렌더링 영역 가장자리의 대표색과 대비되는 검정 또는 흰색 글자 및 아이콘을 사용합니다. 그라데이션, 이미지, 애니메이션에서는 다시 로드할 때까지 색을 고정하여 깜박임을 방지합니다.
- 전체 화면 모드: 언제든 몰입형 전체 화면으로 전환할 수 있고 설정에서 `전체 화면 모드로 시작`을 켤 수 있습니다.
- 외부 링크: 페이지 안의 http/https 링크를 누르면 시스템 브라우저로 전달되며 페이지 내 앵커 이동은 그대로 작동합니다.
- 다국어: 인터페이스, 사용 설명, README, changelog를 10개 언어로 제공합니다.

### 사용 방법

******

1. [Releases](https://github.com/SuperMonster003/AutoJs6-Plugin-HTML-Previewer/releases) 페이지에서 최신 플러그인 APK를 내려받아 기기에 설치합니다.
2. AutoJs6의 플러그인 센터를 열고 `HTML 미리보기` 플러그인을 활성화합니다.
3. AutoJs6 파일 관리자에서 보고 싶은 HTML 또는 MHTML 파일을 찾아 해당 파일의 더보기 메뉴 (추가 작업)를 엽니다.
4. `HTML 미리보기`를 선택하면 페이지가 전용 뷰어에서 열립니다.
5. 읽는 동안 오른쪽 위 메뉴에서 텍스트 검색, `소스 보기`와 `미리보기 보기` 전환, `PDF 내보내기`, `새로 고침`, `전체 화면 모드` 전환을 사용하고 `설정`에서 글자 크기, 테마, 네트워크 이미지, 전체 화면 시작을 조정할 수 있습니다. 뒤로 가기 키로 검색을 닫거나 전체 화면을 종료하거나 뷰어를 닫습니다.

> 플러그인 센터에 플러그인이 보이지 않으면 먼저 AutoJs6를 최신 버전 (내부 빌드 5269 이상)으로 업데이트하세요. Explorer Action v2는 단일 파일의 기본 미리보기 버튼과 메뉴를 지원하며 문서와 상위 폴더의 임시 읽기 권한을 사용합니다. AutoJs6 빌드 5269 이상이 필요합니다.

### 지원 형식

******

플러그인은 다음 확장자를 인식하며 호스트가 `text/html`, `application/xhtml+xml`, `multipart/related`, `application/x-mimearchive`로 명시한 확장자 없는 파일도 허용합니다:

```text
html, htm, shtm, shtml, xht, xhtml, mht, mhtml
```

8 MB 이하 파일은 전체를 불러옵니다. 더 큰 일반 HTML은 확인 후 처음 8 MB만 잘린 위치와 함께 표시할 수 있지만 MHTML은 완전해야 하므로 제한 초과 시 거부합니다. HTML 디코딩은 BOM, MIME 문자 집합, 앞부분의 `meta charset` 또는 `http-equiv`, UTF-8 순으로 사용합니다. MHTML은 제한된 MIME 중첩과 identity, quoted-printable, Base64 전송 인코딩을 지원합니다.

### 자주 묻는 질문

******

#### 페이지의 버튼과 동적 효과가 왜 반응하지 않나요?

스크립트는 기본적으로 비활성화됩니다. 신뢰할 수 있는 완전한 일반 HTML 파일에서는 설정의 상호작용 모드를 켜면 JavaScript, 버튼 이벤트, WebGL, 로컬 저장소를 사용할 수 있습니다. MHTML, 잘린 HTML, 소스 보기, PDF 내보내기는 항상 스크립트를 비활성화합니다.

#### 일부 이미지나 스타일이 왜 표시되지 않나요?

로컬 리소스는 허용된 폴더 또는 선택한 MHTML에서 읽습니다. 안전 모드는 공개 HTTPS 이미지를 허용하고, 상호작용 모드는 네트워크 리소스를 켜면 공개 HTTPS 스크립트, 스타일, 요청도 허용합니다. 네트워크를 끄면 WebView 외부 요청을 차단합니다. 상호작용 스크립트는 원격 서비스에 페이지 데이터를 보낼 수 있으므로 신뢰할 수 있는 페이지에서만 사용하세요.

#### 미리보기가 브라우저와 완전히 같지 않은데 정상인가요?

기본 안전 모드에서: 정상입니다. 스크립트 제거 외에도 뷰어는 기본 읽기 스타일을 주입하고 일부 고급 기능을 비활성화합니다. 목표는 안전하고 읽기 좋은 화면이지 픽셀 단위 재현이 아닙니다. 최종 표시 결과는 브라우저에서 확인하세요.

#### 이 플러그인이 내 파일을 어딘가로 업로드하나요?

로컬 리소스는 허용된 폴더 또는 선택한 MHTML에서 읽습니다. 안전 모드는 공개 HTTPS 이미지를 허용하고, 상호작용 모드는 네트워크 리소스를 켜면 공개 HTTPS 스크립트, 스타일, 요청도 허용합니다. 네트워크를 끄면 WebView 외부 요청을 차단합니다. 상호작용 스크립트는 원격 서비스에 페이지 데이터를 보낼 수 있으므로 신뢰할 수 있는 페이지에서만 사용하세요.

#### 내보낸 PDF는 어디에 저장되나요?

`PDF 내보내기`는 Android 시스템 인쇄 화면을 엽니다. `PDF로 저장`을 선택한 다음 시스템 파일 선택기에서 이름과 위치를 지정하세요. 플러그인은 저장소에 직접 쓰거나 저장소 권한을 요청하지 않습니다. 소스 보기에서 시작해도 HTML 또는 완전한 MHTML을 다시 읽고 루트 페이지를 정리하며 현재 뷰어 상태는 바꾸지 않습니다.

#### HTML 파일을 편집하거나 웹 사이트 전체를 미리 볼 수 있나요?

현재 버전은 단일 파일 읽기 전용 미리보기에 집중합니다: 편집 기능이 없고 디렉터리를 열거하지도 않습니다. 파일 옆의 리소스는 필요할 때만 읽히며, 플러그인은 호스트가 부여한 임시 읽기 권한만 보유합니다. 앞으로의 계획은 [ROADMAP.md](https://github.com/SuperMonster003/AutoJs6-Plugin-HTML-Previewer/blob/master/ROADMAP.md)에서 확인하세요.

### 권한과 보안

******

대화형 모드는 새 미리보기마다 꺼지며 현재 문서를 신뢰할 때만 명시적으로 켜야 합니다. CSP는 fetch, WebSocket, worker와 프레임을 차단합니다. 대화형 JavaScript는 일반 네트워크 샌드박스가 아니며 WebRTC 같은 API는 리소스 설정과 별개로 통신할 수 있습니다. 모르는 문서는 기본 정적 모드로 여세요.

- 기본 안전 모드에서: 표시 전 정리: 스크립트, 이벤트 처리기 속성, 포함된 프레임, 포함된 개체, 폼 제출 대상을 제거하고 안전하지 않은 링크와 리소스 주소를 걸러냅니다.
- 쿠키, 직접 파일/content 접근, 네이티브 JavaScript 브리지, 새 창은 계속 비활성화됩니다. 상호작용 모드만 설정과 점수를 위한 로컬 저장소를 허용합니다. 소스 보기와 PDF는 다시 정제한 내용을 사용합니다.
- 대화형 모드는 새 미리보기마다 꺼지며 현재 문서를 신뢰할 때만 명시적으로 켜야 합니다. CSP는 fetch, WebSocket, worker와 프레임을 차단합니다. 대화형 JavaScript는 일반 네트워크 샌드박스가 아니며 WebRTC 같은 API는 리소스 설정과 별개로 통신할 수 있습니다. 모르는 문서는 기본 정적 모드로 여세요.
- 최소 권한: 플러그인은 호스트가 부여한 임시 content URI 읽기 권한만 받고 파일 시스템 경로에는 접근할 수 없습니다. PDF 출력은 플러그인이 저장소에 직접 쓰지 않고 Android 시스템 인쇄 서비스로 전달합니다.
- 입력 제한: 읽기는 8 MB로 제한되며 MHTML은 파트 수, 중첩, 헤더, 디코딩 총량도 제한합니다. 파일 이름과 리소스 경로는 엄격히 검증되어 범위 밖 접근을 막습니다.
- 현재 신뢰하는 문서에만 사용하세요. WebRTC 같은 API는 리소스 설정과 별개로 통신할 수 있습니다. 새 미리보기는 항상 스크립트가 꺼집니다.
- 정적 미리보기와 제어된 HTTPS 리소스 클라이언트는 공용 DNS 주소를 검증하고 연결에 고정하며 모든 리디렉션을 다시 검증합니다. 리소스 설정은 이 클라이언트를 제어하며 GET과 HEAD만 지원합니다.

기본 안전 모드에서: 소스 매니페스트는 네트워크 권한 (HTTPS 이미지가 켜진 경우 사용)과 AutoJs6 플러그인 권한만 요청합니다. AndroidX는 내보내지 않은 동적 수신기를 보호하기 위해 패키지 범위의 서명 권한도 자동으로 추가하지만 기기 데이터 접근 권한은 부여하지 않습니다. 네트워크 이미지를 끄면 WebView는 외부 요청을 보내지 않습니다. PDF 대상 위치 접근은 Android 인쇄 및 파일 선택 화면이 담당하므로 저장소, 미디어, 카메라, 위치 등 다른 민감한 권한은 요청하지 않습니다.

### 플러그인 인터페이스

******

다음 정보는 개발자용입니다. 호스트는 다음 식별 정보로 플러그인을 검색하고 실행합니다:

```text
application id: io.github.supermonster003.autojs6.plugin.htmlpreviewer
service action: org.autojs.plugin.EXPLORER_ACTION
execute action: org.autojs.plugin.EXPLORER_ACTION_EXECUTE
plugin id: html-previewer
engine: explorer-action
variant: default
protocol version: 2
minimum host build: 5269
audited host build: 5279
audited host protocol: 22
```

Explorer Action v2는 단일 파일의 기본 미리보기 버튼과 메뉴를 지원하며 문서와 상위 폴더의 임시 읽기 권한을 사용합니다. AutoJs6 빌드 5269 이상이 필요합니다.

- [Explorer Action 호환성 매트릭스 보기](https://github.com/SuperMonster003/AutoJs6-Plugin-HTML-Previewer/blob/master/docs/explorer-action-compatibility.md)

### 로드맵

### 릴리스 기록

******

#### v1.1.0

_2026/09/13_

- `기능` 화면에서 현지화된 로컬 릴리스 기록을 표시하고 영어 대체 제공
- `수정` 정적 미리보기와 제어된 HTTPS 리소스 클라이언트는 공용 DNS 주소를 검증하고 연결에 고정하며 모든 리디렉션을 다시 검증합니다. 리소스 설정은 이 클라이언트를 제어하며 GET과 HEAD만 지원합니다.
- `수정` 현재 신뢰하는 문서에만 사용하세요. WebRTC 같은 API는 리소스 설정과 별개로 통신할 수 있습니다. 새 미리보기는 항상 스크립트가 꺼집니다.
- `수정` 원격 리소스를 불러올 때 HTTP 206 및 다른 성공 상태 코드 유지
- `개선` 릴리스 서명 설정, 예상 APK 구성 및 문서 재생성 결과 검증
- `의존성` 제어된 HTTPS 리소스 로드를 위해 OkHttp 4.12.0 추가

#### v1.0.1

_2026/09/11_

- `기능` 스크립트는 기본적으로 비활성화됩니다. 신뢰할 수 있는 완전한 일반 HTML 파일에서는 설정의 상호작용 모드를 켜면 JavaScript, 버튼 이벤트, WebGL, 로컬 저장소를 사용할 수 있습니다. MHTML, 잘린 HTML, 소스 보기, PDF 내보내기는 항상 스크립트를 비활성화합니다.
- `수정` 플러그인 센터에서 플러그인을 활성화할 때 오류로 실패할 수 있는 문제
- `수정` 기본 미리보기 버튼의 프로토콜 거부 및 설정 충돌 수정; 호스트 외관, 표시줄 색상, 대화상자 흑백 컨트롤 동기화
- `개선` 더 간결한 플러그인 이름과 설명, 더 읽기 쉬운 사용자 문서
- `개선` 빌드 시 의도하지 않은 네이티브 의존성을 거부하고 JSON 보고서 생성

#### v1.0.0

_2026/08/06_

- `기능` 첫 릴리스: AutoJs6 파일 관리자에서 HTML 파일용 `HTML 미리보기` 메뉴 작업 제공 (플러그인 ID `html-previewer`)

- `기능` 다국어: 인터페이스, 사용 설명, README, changelog를 10개 언어로 제공

### 빌드

******

```powershell
.\gradlew.bat :app:assembleDebug
```

Release 빌드:

```powershell
.\gradlew.bat :app:assembleRelease
```

빌드 매개변수는 `version.properties`에서 가져옵니다. 현재 최소 SDK는 24이고 대상 SDK는 36입니다.

### 현지화와 문서 생성

******

```text
.readme/common.json
.readme/lang_*.json
.readme/template_readme.md
.changelog/lang_*.json
.changelog/template_changelog.md
.python/generate_markdown.py
app/src/main/assets/doc/CHANGELOG-*.md
app/src/main/res/values-*/strings.xml
app/src/main/res/raw-*/plugin_instruction.md
```

`strings.xml`은 플러그인 정보와 뷰어 UI를 현지화하고 `plugin_instruction.md`는 호스트에 표시되는 사용 설명을 제공합니다. README와 changelog는 반드시 `.readme/`와 `.changelog/`의 JSON 소스를 수정한 뒤 `py .python/generate_markdown.py`를 실행해 다시 생성하며, 생성물은 손으로 편집하지 않습니다. `py .python/generate_markdown.py --check`로 소스와 생성물의 동기화를 검증할 수 있습니다.
